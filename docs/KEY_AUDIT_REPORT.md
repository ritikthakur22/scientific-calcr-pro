# Key Audit Report (Casio fx-991ES Plus Layout)

## Control Keys
- **SHIFT**: WORKING (Toggles shift state)
- **ALPHA**: WORKING (Toggles alpha state)
- **D-Pad (Up, Down, Left, Right)**: WORKING (Navigates cursor)
- **MODE**: WORKING (Triggers onModePressed callback)
- **SETUP** (Shift+MODE): UNIMPLEMENTED (Currently does nothing, needs UI callback implementation)
- **ON**: WORKING (Triggers onClear callback)

## Scientific Zone - Row 1
- **CALC**: BROKEN (Appends `solve(`, parser does not evaluate correctly)
- **SOLVE** (Shift+CALC): BROKEN (Same as CALC)
- **=** (Alpha+CALC): WORKING (Appends `=`)
- **∫dx**: PARTIAL (Appends `∫(`, parser lacks direct symbol integration matching without specific formatting)
- **d/dx** (Shift+∫dx): PARTIAL (Appends `d/dx(`, requires specific parser support)
