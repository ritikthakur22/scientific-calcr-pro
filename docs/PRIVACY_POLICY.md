# Privacy Policy - Scientific CalcR Pro

**Last Updated:** 2026-06-16

Scientific CalcR Pro is designed with user privacy as its highest priority. The application operates as an offline-first tool.

## 1. Data Collection & Sharing
*   **Zero Personal Data Collection:** Scientific CalcR Pro does not collect, monitor, track, or share any personal identifier, user location, account information, or device settings.
*   **Zero Analytical Tracking:** The app does not include any third-party advertising SDKs, tracking pixels, or analytic tools (e.g. Firebase Analytics or Mixpanel).
*   **Zero Network Requests:** All calculations, symbolic math operations (CAS), and graphing runs are executed locally on the device. The application does not send data to any remote servers.

## 2. Local Storage
*   **Calculator History:** Calculation history is stored locally in an on-device SQLite database. You can clear this history at any time using the "Clear History" button on the history screen.
*   **Exam Mode:** When Exam Mode is enabled, the history database is locked, preventing access during examinations.

## 3. Policy Changes
If we update this privacy policy, we will publish the changes directly inside the application settings.
