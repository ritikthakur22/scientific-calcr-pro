**Scientific CalcR Pro** is a highly capable, clean, and intuitive scientific calculator built with Flutter. It is **purely 100% free and open-source**. 

This project was built from scratch by a **learning kid** aiming to understand app development while building something genuinely useful for students, engineers, and math enthusiasts! 🚀

---

## ✨ Features

- **Advanced Scientific Calculator:** Perform complex mathematical operations effortlessly.
- **Computer Algebra System (CAS):** Solve equations, calculate derivatives, and compute integrals.
- **Graphing Capabilities:** Plot functions and analyze graphs in real-time.
- **Unit Conversions & Matrix Operations:** Handy built-in tools for physics and linear algebra.
- **Local History:** Automatically saves your calculation history locally so you never lose your work.
- **Modern User Interface:** A smooth, responsive, and distraction-free design.
- **No Ads, No Tracking:** Purely open-source and respects your privacy.

## 🛠️ Built With (Tech Stack)

This application is built leveraging powerful open-source technologies:

- **[Flutter](https://flutter.dev/) & Dart:** For cross-platform high-performance UI.
- **[Riverpod](https://riverpod.dev/):** For clean, predictable state management.
- **[sqflite](https://pub.dev/packages/sqflite):** For local database and history storage.
- **[fl_chart](https://pub.dev/packages/fl_chart):** For rendering beautiful mathematical graphs.
- **[math_expressions](https://pub.dev/packages/math_expressions):** For parsing and evaluating math expressions.
- **[Nerdamer](https://nerdamer.com/):** A lightweight Javascript CAS used for solving equations and calculus.
